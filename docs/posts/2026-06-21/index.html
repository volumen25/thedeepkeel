Zoom G3Xn “Princeton” Patch Checklist

Guitar: Fender Telecaster MIJ, neck pickup, Master Volume ~9, Master Tone ~9
Zoom: G3Xn, Firmware 2.20, Patch cell 106, Patch name “Princeton” Goal: Warm, articulate Princeton Reverb-style clean tone with shimmer trem and spring reverb
Amp: Fender Blues Jr III (real amp, miked — no Zoom amp/cab sim used)

Signal Chain

Guitar → RackComp → RC Boost → Tremolo → FD Spring → Zoom output → Blues Jr input → mic

Note: guitar Volume/Tone currently near max (9/9) rather than rolled back. Brighter/more aggressive than original plan — if tone feels too bright or aggressive once recorded, roll Tone back to 6-7 as first adjustment.

Block 1 — RackComp (DYNAMICS)

Block 2 — RC Boost (DRIVE)

Block 3 — Tremolo (MODULATION)

Block 4 — FD Spring (REVERB) — sole reverb source (Option A)

Decision: FD Spring is the sole meaningful reverb source. Blues Jr’s physical Reverb dial has no true zero (range is 1–12), so it stays at its physical minimum (1) — this contributes a negligible touch of onboard spring underneath and is not treated as problematic stacking.

Block 5 — Rhythm (RHYTHM AND LOOPER) — practice aid, not part of the recorded tone

  • Pattern: Metro4 4/4
  • Volume: 4
  • Reminder: disable or mute before any actual take — this is a metronome click, not a tone-shaping effect, and isn’t meant to bleed into the final recording

Amp Settings — Blues Jr III (dials 1–12, no true zero)

Mic Setup — Blue Yeti (on stock desktop stand, floor placement)

Notes: - Forward tilt = vertical aim adjustment (reaches cone height), not the off-axis angle - Sideways base offset = true off-axis angle (softens pick attack/harshness) - Both adjustments are used together in this floor setup since the stand can’t swivel independently
